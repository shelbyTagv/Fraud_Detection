================================================================
          FORENSIC ANALYTICS PROTOTYPE — RUN GUIDE
================================================================
This guide details the complete step-by-step process to set up 
the environment and run the Forensic Analytics system on Windows.

----------------------------------------------------------------
STEP 1: INSTALL SYSTEM PREREQUISITES
----------------------------------------------------------------
Before running the setup, ensure the following two applications 
are installed on your Windows machine:

1. Python 3.10 or newer
   - Download from: https://www.python.org/downloads/
   - IMPORTANT: When installing, check/tick the box that says:
     "Add Python.exe to PATH" before clicking "Install Now".
     (If you miss this step, the setup script will fail).

2. Node.js (LTS version recommended)
   - Download from: https://nodejs.org/
   - Follow the standard installer instructions.

----------------------------------------------------------------
STEP 2: ENVIRONMENT AND DEPENDENCY SETUP (FIRST TIME ONLY)
----------------------------------------------------------------
Once the prerequisites are installed, you need to set up the 
local virtual environment and install the package dependencies:

1. Navigate to the project root directory in File Explorer.
2. Locate and double-click the file named:
   --> setup.bat
3. A command prompt window will open and perform the following:
   - Check if Python and Node.js are installed correctly.
   - Create a Python virtual environment ("venv") in "backend/".
   - Activate the virtual environment and install pip packages 
     (FastAPI, Uvicorn, Pandas, XGBoost, Scikit-learn, etc.).
   - Automatically generate the synthetic transaction data file:
     "backend/sample_data.csv".
   - Install React frontend packages (takes 1-2 minutes).
4. Wait until the window displays:
   "============================================================
    SETUP COMPLETE
    ============================================================"
5. Press any key to close the window.

----------------------------------------------------------------
STEP 3: RUNNING THE APPLICATION
----------------------------------------------------------------
To boot up the local servers and start using the application:

1. Double-click the file named:
   --> START_ALL.bat
2. This will open two separate terminal windows in the background:
   - "Forensic Analytics - Backend": Runs the FastAPI server 
     on http://localhost:8000
   - "Forensic Analytics - Frontend": Runs the React server 
     on http://localhost:3000
3. The system will automatically open http://localhost:3000 
   in your default web browser after a few seconds.
4. **IMPORTANT**: Keep both terminal windows open while using 
   the system. Closing either window will stop that server.

----------------------------------------------------------------
STEP 4: USING THE SYSTEM & TESTING
----------------------------------------------------------------
1. Once the browser opens at http://localhost:3000, click 
   "Register here" to create a new user account.
2. Log in using your new credentials.
3. On the dashboard, click "Choose CSV File" and select:
   --> backend/sample_data.csv
4. Click "Run Analysis" and wait about 5 seconds.
5. Explore the analytics tabs (Benford's Law, ML, Network, etc.) 
   to view the results.
6. Click "Export PDF Report" to download a summary report.

----------------------------------------------------------------
STEP 5: STOPPING THE SYSTEM
----------------------------------------------------------------
When you are done using the system, you can stop the servers by:

- Double-clicking the file named:
  --> STOP_ALL.bat
  (This will automatically terminate both backend and frontend 
  background server processes and free up ports 8000 and 3000).
- Alternatively, you can simply close both command prompt windows.

----------------------------------------------------------------
WINDOWS TROUBLESHOOTING TIPS
----------------------------------------------------------------
- Error: "Python is not recognized as an internal or external command"
  - Uninstall Python and reinstall it, making sure to tick the 
    "Add Python.exe to PATH" checkbox at the start of the installer.
- Error: "Port 8000 (or 3000) is already in use"
  - Double-click "STOP_ALL.bat" to terminate any phantom processes 
    that did not close properly, then run "START_ALL.bat" again.
